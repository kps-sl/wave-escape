# Wave Escape (web playtest build)

A one-touch endless runner: outrun the wave. Tap / click / Space to jump,
tap again to double-jump, hold while falling to glide.

**Play:** open the GitHub Pages site for this repo (index.html).
Built with Godot 4.7 — web export v0.2 (fluid-animation build).
Source project lives outside this repo; this repo hosts the playable build only.
